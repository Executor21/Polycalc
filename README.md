# 📘 Εγχειρίδιο Χρήστη Polycalc

## 1. Εισαγωγή

Καλώς ήρθατε στο **Polycalc** - τον έξυπνο υπολογιστή κοινόχρηστων εξόδων που θα κάνει τη διαχείριση της πολυκατοικίας σας να μοιάζει με πίστα χορού! 💃

**Τι κάνει το Polycalc;**
- 🏢 Αυτοματοποιεί τον υπολογισμό των κοινόχρηστων εξόδων
- 📊 Κατανομεί τα έξοδα ανά διαμέρισμα με βάση τα χιλιοστά
- 💾 Αποθηκεύει όλα τα δεδομένα αυτόματα
- 📄 Δημιουργεί αναφορές και πίνακες έτοιμους για εκτύπωση

**Γιατί να το χρησιμοποιήσετε;**
Γιατί το να υπολογίζετε με το χέρι τα κοινόχρηστα είναι σαν να προσπαθείτε να φτιάξετε καφέ με αμπεζόν... δουλεύει, αλλά δεν είναι και η πιο έξυπνη λύση! 😄

## 2. Εγκατάσταση

### 💻 Προϋποθέσεις συστήματος
- **Λειτουργικό σύστημα**: Windows 10 ή νεότερο
- **Αποθήκευση**: Τουλάχιστον 100 MB ελεύθερος χώρος
- **Δικαιώματα**: Συνιστάται εκτέλεση ως διαχειριστής (Administrator)

### 📦 Οδηγίες εγκατάστασης
1. **Εκτέλεση εγκαταστάτη**: Κάντε διπλό κλικ στο `Polycalc Setup.exe`
2. **Ακολουθήστε τον οδηγό**: 
   - Πατήστε "Next" για να συνεχίσετε
   - Διαλέξτε φάκελο εγκατάστασης (προτείνεται ο προεπιλεγμένος)
   - Επιλέξτε αν θέλετε συντόμευση στην επιφάνεια εργασίας
3. **Ολοκλήρωση**: Πατήστε "Finish" και... μπράβο! Εγκαταστήσατε επιτυχώς το Polycalc! 🎉

> 💡 **Συμβουλή**: Αφήστε τον προεπιλεγμένο φάκελο (C:\Polycalc\) για να αποφύγετε θέματα δικαιωμάτων.

### ⚙️ Πρώτη εκκίνηση
1. Βρείτε το Polycalc στο μενού Έναρξη ή στην επιφάνεια εργασίας
2. Κάντε διπλό κλικ για εκκίνηση
3. Αν σας ζητηθούν δικαιώματα διαχειριστή, πατήστε "Ναι" - δεν πρόκειται να φάει το σκύλο σας, υπόσχεμαι! 🐶
4. Το πρόγραμμα θα δημιουργήσει αυτόματα τα απαραίτητα αρχεία ρυθμίσεων

## 3. Ξεκινώντας

### 🎯 Η κύρια οθόνη
Το Polycalc έχει 3 κύριες καρτέλες που είναι τόσο εύκολες όσο το 1-2-3:

#### 📊 Καρτέλα 1: Δαπάνες
Εδώ εισάγετε όλα τα έξοδα της πολυκατοικίας:
- **Κοινόχρηστα** (καθαριότητα, ρεύμα, νερό, πυρασφάλεια, κηπουρός, άλλα)
- **Ασανσέρ**
- **Θέρμανση** 
- **Έκδοση κοινόχρηστων**
- **Αποθεματικό**

> ⚡ **Μαγικό χαρακτηριστικό**: Οι υπολογισμοί γίνονται αυτόματα καθώς πληκτρολογείτε!

#### 🏢 Καρτέλα 2: Διαμερίσματα
Εδώ διαχειρίζεστε τα διαμερίσματα της πολυκατοικίας:
- Προσθέστε νέα διαμερίσματα
- Ορίστε ιδιοκτήτες και χιλιοστά
- Επεξεργαστείτε ή διαγράψτε υπάρχοντα

#### 📈 Καρτέλα 3: Αναλυτικά
Βλέπετε αναλυτικά τα έξοδα κάθε διαμερίσματος και μπορείτε να αποθηκεύσετε τα αποτελέσματα σε αρχείο.

## 4. Χρήση του Προγράμματος

### 🔢 Βήμα 1: Εισαγωγή Δαπανών
1. Πηγαίνετε στην καρτέλα "📊 Δαπάνες"
2. Συμπληρώστε τα ποσά σε κάθε πεδίο
3. Πατήστε "💾 ΑΠΟΘΗΚΕΥΣΗ" για να αποθηκεύσετε

### 🏠 Βήμα 2: Διαχείριση Διαμερισμάτων
1. Πηγαίνετε στην καρτέλα "🏢 Διαμερίσματα"
2. Πατήστε "➕ ΠΡΟΣΘΗΚΗ" για νέο διαμέρισμα
3. Συμπληρώστε:
   - Ονομασία διαμερίσματος (π.χ. "Δ1")
   - Όνομα ιδιοκτήτη
   - Χιλιοστά κοινόχρηστων
   - Χιλιοστά ασανσέρ
   - Χιλιοστά θέρμανσης

### 🧮 Βήμα 3: Υπολογισμός & Αποθήκευση
1. Πατήστε "🧮 ΥΠΟΛΟΓΙΣΜΟΣ" για να δείτε τα αποτελέσματα
2. Στην καρτέλα "📈 Αναλυτικά" επιλέξτε διαμέρισμα για λεπτομέρειες
3. Πατήστε "💾 ΑΠΟΘΗΚΕΥΣΗ ΣΕ ΑΡΧΕΙΟ" για εξαγωγή

### 💾 Βήμα 4: Αποθήκευση για Polyfund
Πατήστε "💾 INI FOR POLYFUND" για να δημιουργήσετε αρχείο συμβατό με το Polyfund.

## 5. Συχνές Ερωτήσεις (FAQ)

### ❓ Ε: Γιατί μου λέει "Access Denied" όταν προσπαθώ να αποθηκεύσω;
**Α**: Το Windows είναι λίγο "drama queen" με τα δικαιώματα. Δοκιμάστε να εκτελέσετε το πρόγραμμα ως Administrator (Δεξί κλικ → "Run as administrator").

### ❓ Ε: Μπορώ να μετακινήσω το πρόγραμμα σε άλλο σκληρό δίσκο;
**Α**: Ναι, αλλά προτείνουμε να παραμείνει στο C:\ για να αποφύγετε θέματα δικαιωμάτων. Ο υπολογιστής σας δεν είναι σαν το παιδί σας - δεν του αρέσει να αλλάζει σπίτι συχνά! 🏠

### ❓ Ε: Χάθηκαν τα δεδομένα μου μετά από αναβάθμιση;
**Α**: Όχι! Τα δεδομένα σας αποθηκεύονται στο αρχείο `Polykatoikia_Data.ini` που παραμένει ανεξάρτητα από τις ενημερώσεις.

### ❓ Ε: Πώς μπορώ να εκτυπώσω τους πίνακες;
**Α**: Χρησιμοποιήστε το κουμπί "📄 ΑΠΟΘΗΚΕΥΣΗ ΠΙΝΑΚΑ" που δημιουργεί ένα όμορφο αρχείο κειμένου έτοιμο για εκτύπωση.

## 6. Αντιμετώπιση Προβλημάτων

### 🔧 Το πρόγραμμα δεν ανοίγει
- Ελέγξτε αν το antivirus μπλοκάρει το πρόγραμμα
- Δοκιμάστε να εκτελέσετε ως Administrator
- Ελέγξτε αν το Windows SmartScreen το εμποδίζει

### 🔧 Το πρόγραμμα "κολλάει"
- Πατήστε Ctrl + Alt + Del → Task Manager → Βρείτε το Polycalc → End Task
- Επανεκκινήστε το πρόγραμμα

### 🔧 Καθαρή επανεγκατάσταση
1. Απεγκαταστήστε το πρόγραμμα
2. Διαγράψτε τον φάκελο `C:\Polycalc\`
3. Επανεγκαταστήστε από την αρχή
